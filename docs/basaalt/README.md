# BASAALT: Behaviour Analysis & Simulation All Along systems Life Time

This projects aims at developing the BASAALT methods

* A repo for all the current material: [https://github.com/CoCoVaD/basaalt](https://github.com/CoCoVaD/basaalt), including:
    * The [PDF documentation](https://github.com/CoCoVaD/basaalt/blob/main/BASAALT-and-FORM-L.pdf)

* This repo for the future online documentation of the language
